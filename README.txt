SHARMA CLASSES WEBSITE — QUICK START

FILES
- index.html: the full responsive starter website (HTML, CSS, JavaScript in one file).

HOW TO PREVIEW
1. Extract the ZIP file.
2. Open the sharma_classes_website folder.
3. Double-click index.html. It opens in Chrome, Edge, Firefox, or Safari. Internet is needed for the external stock photos.

BEFORE PUBLISHING
1. Replace the placeholder phone, email, address, opening hours, and batch details.
2. In index.html, find YOUR_EMAIL_HERE and replace it with the real enquiry email. The form currently opens the visitor's email app; it is not a database-backed form.
3. Replace stock photos with real photos of Anish Sharma, your classrooms, and students (with permission).
4. Remove courses you do not teach and add accurate fees, durations, syllabus, qualifications, reviews, and claims. Do not publish invented student counts, ratings, placement claims, or accreditation.
5. Update the WhatsApp/contact button if you want a direct WhatsApp link. Use your international phone number without spaces in a wa.me link.

HOW TO PUBLISH (BEGINNER-FRIENDLY)
Option A — Netlify: create an account, open the manual deploy/drop area, and upload the extracted folder or a ZIP containing index.html. Follow the platform's current prompts to publish and get a temporary URL.
Option B — GitHub Pages: create a repository, upload index.html, enable Pages in repository settings, and wait for the published URL.
For a custom domain, buy a domain from a registrar and connect its DNS settings to the hosting provider using the provider's instructions.

LIMITATIONS
This is a front-end starter site, not a full learning management system. It has no admin dashboard, student accounts, payment gateway, course video hosting, or stored enquiry database. Those require additional services/backend setup.
